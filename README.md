# 🏡 AI-Based Intelligent Real Estate Sale & Recommendation System

A full-stack web application with an AI-powered property recommendation engine.

## 📁 Project Structure

```
.
├── frontend/   # React.js + Ant Design
└── backend/    # Node.js + Express REST API
```

## 🚀 Getting Started

### Frontend
```bash
cd frontend
npm install
npm start
```

### Backend
```bash
cd backend
npm install
npm run dev
```

## 🔧 Tech Stack

| Layer     | Technology                        |
|-----------|-----------------------------------|
| Frontend  | React.js, Ant Design, React Router |
| Backend   | Node.js, Express.js               |
| Database  | MongoDB (Mongoose)                |
| Auth      | JWT                               |
